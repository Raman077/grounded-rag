Nimbus Release Notes

Version 4.2 (September 2026)

Version 4.2 adds lifecycle rules that move objects to the archive tier automatically after a chosen number of days. Archive storage costs $0.004 per GB-month and objects can be restored within 12 hours.

The command-line tool now supports resumable uploads with the --resume flag.

Version 4.1 (June 2026)

Version 4.1 introduced the ap-southeast region, located in Singapore, and raised the maximum object size for multipart uploads from 1 TB to 5 TB.

Deprecations

The v1 API will be shut down on 1 March 2027. Customers should migrate to the v2 API, which has been generally available since version 3.0.
